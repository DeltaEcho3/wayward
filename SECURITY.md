# Security

If you find a security problem in Wayward, please tell us privately and not in a public issue.

- Use GitHub's private vulnerability reporting: on this repository, open the **Security** tab and choose **Report a vulnerability**.
- Or email trywayward@gmail.com.

Please include the Wayward version (**Settings** > **About Wayward**), your Android version and phone, and the steps that show the problem. Leave out anything private that isn't needed to show it.

We read every report and will answer as soon as we can. Please give us a reasonable time to fix a problem before you write about it in public.

Wayward is closed source, so reports about the app are welcome from testing the app as it ships. The open-source parts it includes are listed in [oss/](oss/); a problem in one of those is best reported to its own project as well.
