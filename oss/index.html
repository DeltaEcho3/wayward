Open-source code in Wayward

Wayward's own code is proprietary, but it includes open-source software. The full list of components and licenses is in the app under Settings > About Wayward > Legal information > Open-source licenses. These are the sources their licenses require us to offer, exactly as used in Wayward.

uBlock Origin 1.77.0, modified by Wayward (GPL-3.0)

Wayward changed it: it added a file that connects it to Wayward's settings, and changed others of its files, from 2026-10-27 to 2026-11-25, carried over to uBlock Origin 1.77.0 on 2026-11-24. WAYWARD-CHANGES.txt inside it lists every change, file by file, with its date. The copy Wayward bundles, with its changes (tar.gz) · uBlock Origin 1.77.0's own source (tar.gz) · upstream: github.com/gorhill/uBlock

FFmpeg 9.0.2 (LGPL-2.1 or later)

Built by Wayward with LGPL parts only, as shared libraries with the ffmpeg and ffprobe programs linked to them. Source (tar.xz) · signature · build script · configure options

GeckoView 161.0 (MPL-2.0)

No file of it is changed. Its archive of the engine's own scripts and pages (omni.ja) ships without parts Wayward never uses: the developer tools server, the test-automation driver (Marionette), settings for other processors, and the engine's diagnostic about: pages with their texts. The script that takes them out, which lists them (it uses zip_without.py) · source: hg.mozilla.org/releases/mozilla-release, tag FIREFOX_161_0_RELEASE. Its two ANGLE graphics libraries (libGLESv2_angle.so, libEGL_angle.so) are left out: the engine loads them only when a setting Wayward never turns on asks for them.
